== 环境准入前置（**环境事实，非产品缺陷** —— 免责澄清）==
麒麟 KySec 以**完整性标签**拦执行新二进制（实测：`/bin/true` 原地可跑，
**复制**到 /tmp 即 `Permission denied`）。实测标签面差异：

  受信系统二进制 /bin/true:
    security.ksip="none:none:original:9999"
    security.kysec="none:none:original"
    security.boxadm=0sAAAAAAAAAAAAAAAA

  未打标新文件 /tmp/t2:
    security.ksip="none:none:unknown:16787215"

故我方工具链与构建产物须先打标（**范围仅限我方文件**，不触碰机器全局安全控制）：

  setfattr -n security.kysec -v "none:none:original"        <file>
  setfattr -n security.ksip  -v "none:none:original:9999"   <file>

`go test -exec` 包装器 `~/kylin-labelrun.sh`（13 行 sh）在每次 exec 测试二进制前
执行上述两条打标，再交还控制权——因为 go 编译出的测试二进制每次都是**新文件**。
**边界**：不得以关闭全局安全控制（`setstatus -f exectl off` 等）替代打标。

== 本轮验证过程中排除的两项环境前置（均非产品缺陷）==
1. **cgo 缺 libc 开发头**：麒麟装有 gcc 但无 crt1.o/crti.o → `CGO_ENABLED=1`（默认）
   下编译中止（`compilation terminated`）。修复=`CGO_ENABLED=0`（亦即 R-1695-4
   可复现构建配方所钉）。修复后 31 包全绿。
2. **git 缺失**：releasecheck 的 `test-config-git` 项需 `git ls-files`；麒麟镜像默认
   无 git → 该项 FAIL。修复=`apt-get install git`（1:2.25.1-1kylin3.14+esm3）。
   修复后该包转绿。
