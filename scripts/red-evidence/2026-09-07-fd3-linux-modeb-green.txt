# FD3 S4 Linux 模式 B 集成实证（2026-09-07——goalos-test 真机）

环境：goalos-test（Ubuntu 24.04.4 kernel 6.8，AppArmor 限 userns 默认策略=模式 B 面）。
面=真模式 B 沙箱（landlock+seccomp 免 userns）非 mock。

## 形态定案（设计裁决——先于代码）

模式 B seccomp 白名单放行 AF_UNIX（socket/socketpair 域名白名单实证在位）→
沙箱内进程**直连**宿主 unix socket，无 AC 回环隔离问题（WinAC 特有）——
**Linux 面无 fd3d 转发器**。不对称诚实标注：
- Windows=回环端口透明映射（agent 无感知——fd3d 承接）；
- Linux=沙箱进程对 unix socket 直说 FD3 帧（seccomp 拦 AF_INET connect——
  回环透明在 Linux 面构造性不可能）；socket 落 tmpDir（Landlock 已授写权面）。

L1 的边界活性证明链：同 session Precheck 绿（home 写拒+出站拒）=模式 B 边界在位实锤；
L1=边界内的治理中继面工作（AF_UNIX 白名单内）；L3=中继面不削弱 IP 边界。
